# Data provenance

`cleaned_local/` contains a small lab-cleaned sample derived from the Mapudungun–Spanish corpus introduced by Duan et al. (2020). It is data, not MIT-licensed repository code.

The upstream corpus is distributed under the Creative Commons Attribution-NonCommercial-ShareAlike 3.0 license. See [`LICENSE-DATA.md`](LICENSE-DATA.md). Preserve attribution, noncommercial use, and share alike terms when redistributing derivatives.

The full corrected experimental splits are intentionally absent from Git. The scripts expect aligned UTF-8 text with Mapudungun in `src.txt` and Spanish in `tgt.txt`.
